About “To”: this is the Ethereum EIP-7002 system contract — part of the protocol, installed by the Pectra upgrade. Explorers show it “unverified” because it has no Solidity source (it is hand-written protocol bytecode); it is not a third-party contract. It can only queue an exit request and take the fee — it has no code path to move your other funds.
